# Qwen3-TTS 1.7B Base

Локальная установка модели находится в `models/Qwen3-TTS-12Hz-1.7B-Base`.
Все крупные файлы, окружение и кэши размещены на диске F.

## Запуск

Подготовьте чистую запись голоса длительностью примерно 3–15 секунд и точную
расшифровку того, что произносится в записи. WAV предпочтительнее MP3.

```powershell
.\run.ps1 `
  --text "Текст, который необходимо озвучить." `
  --ref-audio "F:\путь\к\голосу.wav" `
  --ref-text "Точный текст из записи голоса." `
  --output "F:\src\tts\output.wav"
```

Если точной расшифровки нет, можно использовать только тембр голоса, но
сходство и качество обычно будут ниже:

```powershell
.\run.ps1 --text "Проверка синтеза речи." --ref-audio "F:\путь\к\голосу.wav" --speaker-only
```

Перед генерацией желательно закрыть игры и другие приложения, активно
использующие видеопамять. Модель занимает около 4 ГБ VRAM сразу после загрузки.
